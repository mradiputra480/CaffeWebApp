CafeSync - Information System Specification
2. Bisnis Proses Flowchart (Business Process Flowchart)
Overview
CafeSync automates operational workflows across three key roles: Staff/Cashier, HRD, and Manager. Below are the text-based business process flowcharts with full branching logic.
2.1 User Authentication & Role Routing Flowchart
Start: User launches CafeSync application and inputs credentials (email/username and password).
Condition (Credentials Check):
IF Invalid: System increments failed login counter. If failed attempts < 3, display "Invalid Credentials" error and prompt retry. If failed attempts >= 3, flag account as temporarily locked for 15 minutes and log security event.
IF Valid: System retrieves user role (STAFF, HRD, MANAGER) and routes to designated portal.
Role Routing Branch:
Branch 1 (STAFF): Redirect to POS Order & Attendance Terminal.
Branch 2 (HRD): Redirect to HR Management & Payroll Portal.
Branch 3 (MANAGER): Redirect to Executive Analytics & Inventory Approval Dashboard.

2.2 POS Order & Payment Processing Flowchart
Start: Cashier selects menu items from catalog grid.
Condition (Stock Availability Check):
IF Stock < Required: System blocks item addition, displays "Insufficient Ingredient Stock" warning, and highlights missing raw ingredients.
IF Stock >= Required: Item added to active cart order.
Action: Cashier initiates checkout and selects payment method.
Payment Branch:
Branch A (Cash Payment): Cashier inputs cash tendered. IF cash < order total, prompt for remaining balance. ELSE, system calculates change, confirms payment, and prints receipt.
Branch B (QRIS Dynamic Payment): System requests QRIS API payload, displays QR barcode on customer screen, and polls payment gateway status. IF payment times out (3 minutes), cancel QR transaction. IF payment succeeds, trigger success callback.
Post-Payment Action: System automatically deducts raw ingredient stocks, updates real-time daily revenue metrics, and sends order ticket to kitchen display screen.
End: Order completed.

2.3 HR Attendance & Shift Management Flowchart
Start: Employee scans NFC ID card or enters PIN at login terminal.
Condition (Shift Validation Check):
IF Scheduled Shift Active: Log Clock-In timestamp, mark status as "On Time".
IF Late (> 15 mins): Log Clock-In timestamp, mark status as "Late", send notification to HRD dashboard.
IF Unscheduled: Prompt for Manager override approval code.
End Shift Action: Employee initiates Clock-Out. System calculates total working hours. IF total hours > scheduled hours, log extra hours into Overtime Accumulator for payroll calculation.

6. Database Schema
SQL Data Definition Language (DDL) Scripts
-- Database Creation
CREATE DATABASE IF NOT EXISTS cafesync_db;
USE cafesync_db;
-- 1. Users Table (Role-Based Access)
CREATE TABLE users (
    user_id INT PRIMARY KEY AUTO_INCREMENT,
    full_name VARCHAR(100) NOT NULL,
    email VARCHAR(100) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role ENUM('STAFF', 'HRD', 'MANAGER') NOT NULL DEFAULT 'STAFF',
    hourly_rate DECIMAL(10,2) NOT NULL DEFAULT 0.00,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
-- 2. HR Attendance Logs
CREATE TABLE attendance (
    attendance_id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL,
    clock_in DATETIME NOT NULL,
    clock_out DATETIME NULL,
    total_hours DECIMAL(5,2) DEFAULT 0.00,
    status ENUM('ON_TIME', 'LATE', 'OVERTIME') DEFAULT 'ON_TIME',
    FOREIGN KEY (user_id) REFERENCES users(user_id) ON DELETE CASCADE
);
-- 3. Ingredients Inventory Table
CREATE TABLE ingredients (
    ingredient_id INT PRIMARY KEY AUTO_INCREMENT,
    item_name VARCHAR(100) NOT NULL,
    current_stock DECIMAL(10,2) NOT NULL DEFAULT 0.00,
    unit VARCHAR(20) NOT NULL, -- e.g., 'grams', 'ml', 'pcs'
    minimum_threshold DECIMAL(10,2) NOT NULL DEFAULT 10.00,
    unit_cost DECIMAL(10,2) NOT NULL DEFAULT 0.00
);
-- 4. Menu Catalog Table
CREATE TABLE menu (
    menu_id INT PRIMARY KEY AUTO_INCREMENT,
    item_name VARCHAR(100) NOT NULL,
    price DECIMAL(10,2) NOT NULL,
    category VARCHAR(50) NOT NULL, -- e.g., 'Espresso', 'Cold Brew', 'Bakery'
    is_available BOOLEAN DEFAULT TRUE
);
-- 5. Recipes Junction Table (Menu - Ingredients Mapping)
CREATE TABLE recipes (
    recipe_id INT PRIMARY KEY AUTO_INCREMENT,
    menu_id INT NOT NULL,
    ingredient_id INT NOT NULL,
    amount_required DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (menu_id) REFERENCES menu(menu_id) ON DELETE CASCADE,
    FOREIGN KEY (ingredient_id) REFERENCES ingredients(ingredient_id) ON DELETE CASCADE
);
-- 6. Orders Master Table
CREATE TABLE orders (
    order_id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT NOT NULL, -- Cashier who processed order
    total_amount DECIMAL(10,2) NOT NULL,
    payment_method ENUM('CASH', 'QRIS') NOT NULL,
    payment_status ENUM('PENDING', 'PAID', 'FAILED') DEFAULT 'PAID',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(user_id)
);
-- 7. Order Details Line Items
CREATE TABLE order_details (
    order_detail_id INT PRIMARY KEY AUTO_INCREMENT,
    order_id INT NOT NULL,
    menu_id INT NOT NULL,
    quantity INT NOT NULL,
    subtotal DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (order_id) REFERENCES orders(order_id) ON DELETE CASCADE,
    FOREIGN KEY (menu_id) REFERENCES menu(menu_id)
);
-- 8. Restock Requests Table
CREATE TABLE restock_requests (
    request_id INT PRIMARY KEY AUTO_INCREMENT,
    ingredient_id INT NOT NULL,
    requested_by_user INT NOT NULL,
    approved_by_user INT NULL,
    quantity_requested DECIMAL(10,2) NOT NULL,
    status ENUM('PENDING', 'APPROVED', 'REJECTED', 'COMPLETED') DEFAULT 'PENDING',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (ingredient_id) REFERENCES ingredients(ingredient_id),
    FOREIGN KEY (requested_by_user) REFERENCES users(user_id),
    FOREIGN KEY (approved_by_user) REFERENCES users(user_id)
);
